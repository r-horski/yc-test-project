# Тестовое задание для Yandex Cloud

Проект предназначен для загрузки и обработки данных о заказах из JSON-файла в SQLite базу данных.

## Структура проекта

- `main.py` — основной скрипт для обработки данных
- `database.py` — константы и пути
- `orders.json` — исходные данные
- `db/` — директория для SQLite-базы (`orders.db`)
- `logs/` — директория для логов (`process.log`)
- `requirements.txt` — зависимости (используются только стандартные библиотеки)

## Как запустить

1. Убедитесь, что установлен Python 3.6+
2. Выполните команду:
   ```bash
   python main.py
   ```
   - Добавьте флаг `--stats`, чтобы после загрузки показать статистику:
   ```bash
   python main.py --stats
   ```

При первом запуске скрипт автоматически создаст директории `db` и `logs`, а также базу данных и лог-файл.

## Как это работает

1. **Инициализация**: создаются необходимые директории (если отсутствуют)
2. **Логирование**: настраивается запись в файл `logs/process.log` и вывод в консоль
3. **База данных**: создаётся таблица `orders` с полями:
   - `order_id` (PRIMARY KEY)
   - `status`
   - `date`
   - `amount`
   - `customer_region`
4. **Чтение данных**: из `orders.json` загружаются все заказы
5. **Обработка**: для каждого заказа извлекаются нужные поля, дата преобразуется из ISO-формата
6. **Вставка с проверкой дубликатов**: перед вставкой проверяется наличие `order_id` в БД
7. **Логирование результата**: фиксируется количество добавленных записей

## Логирование

Логируются следующие события:
- Запуск и завершение процесса
- Создание директорий
- Создание таблицы БД
- Количество загруженных заказов
- Пропущенные дубликаты
- Количество успешно вставленных заказов
- Ошибки при чтении JSON

## Проверка дубликатов

Реализована на двух уровнях:
1. **SQL-уровень**: поле `order_id` — PRIMARY KEY
2. **Приложение**: перед вставкой выполняется запрос:
   ```sql
   SELECT 1 FROM orders WHERE order_id = ?
   ```
   Если запись существует — заказ пропускается, и это логируется

Такой подход предотвращает дублирование данных при повторных запусках скрипта.
